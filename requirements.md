The proposed lunch ordering application is intended to streamline the team's lunch decision-making process, offering a nicer alternative to Slack polls. Key features and goals for the application include: * **Centralized Options:** A repository of all available lunch options. * **Voting System:** A mechanism for the team to vote on where to order lunch. * **Historical Data & Analytics:** Features to track and visualize distribution of choices (e.g., viewing which places are ordered most frequently). * **Post-Lunch Ratings:** A rating system where users can review their order and the restaurant overall, helping others decide what to order in the future. * **Technical Implementation:** The project would serve as a training opportunity for interns to set up an application from scratch—initializing it (potentially using Vue for the frontend), implementing a database for storing persistent data (like user accounts/passwords and static lunch options), and creating a Docker file to produce a build image.
