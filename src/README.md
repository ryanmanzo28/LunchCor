# LunchCor Frontend

This folder contains the Nuxt frontend and server routes for the LunchCor skeleton.

## Scope

- Scaffold only; feature implementation is intentionally deferred.
- API health endpoint is available at `/api/health`.

## Local Development

```bash
npm install
npm run dev
```

Default URL: `http://localhost:3000`

## Production Build Check

```bash
npm run build
```

## Docker

From repository root:

```bash
docker compose up --build
```
